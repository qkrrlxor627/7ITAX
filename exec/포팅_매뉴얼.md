### 1-3. 배포 시 특이사항

#### 아키텍처 개요

```
[Android App] ──HTTPS──→ [Nginx :3000] ──/api/*──→ [Spring Boot :18080]
                              │                          │
                              │ 정적 파일 서빙            ├──→ [PostgreSQL :5432]
                              │ (React SPA)              ├──→ [Redis :6379]
                              │                          └──→ [AI Service :19000]
                              │                                    │
                              │                              [Anthropic Claude]
                              │                              [ChromaDB]
```

#### 로컬 개발 환경 (docker-compose.yml)

`docker-compose.yml`로 인프라(DB, Redis, AI, Worker)를 일괄 기동합니다.

```bash
# 로컬 인프라 기동
ANTHROPIC_API_KEY=<키> AES_ENCRYPTION_KEY=<키> JWT_SECRET=<키> docker compose up -d
```

| 서비스 | 이미지 | 컨테이너명 | 포트 | 비고 |
|--------|--------|-----------|------|------|
| PostgreSQL | `postgres:16` | `tax7i-postgres` | 5432 | DB: `tax7i`, User: `ssafy`, PW: `ssafy` |
| Redis | `redis:7` | `tax7i-redis` | 6379 | PW: `ssafy` |
| AI Service | `./ai` (빌드) | `tax7i-ai` | 8000 | ANTHROPIC_API_KEY 필수 |
| Worker | `./BE` (빌드) | `tax7i-worker` | - | Spring Profile: `worker` |

- PostgreSQL 초기화: `db/init/` 디렉토리의 SQL 파일이 `docker-entrypoint-initdb.d`에 마운트되어 최초 기동 시 자동 실행
- Worker 서비스: `SPRING_PROFILES_ACTIVE=worker`로 실행, DB/Redis/AI에 의존 (healthcheck 통과 후 기동)
- AI → Backend 통신: `http://host.docker.internal:8080` (로컬 Spring Boot와 연동)

#### 헬스체크

| 서비스 | 체크 명령 | 간격 |
|--------|----------|------|
| PostgreSQL | `pg_isready -U ssafy -d tax7i` | 10s, 3회 재시도 |
| Redis | `redis-cli -a ssafy ping` | 10s, 3회 재시도 |
| AI Service | HTTP GET `/api/v1/health/` | 15s, 3회 재시도, 30s 대기 |

#### 영속 볼륨 (docker-compose)

| 볼륨명 | 마운트 경로 | 용도 |
|--------|-----------|------|
| `postgres-data` | `/var/lib/postgresql/data` | DB 데이터 |
| `redis-data` | `/var/lib/redis/data` | Redis 데이터 |
| `ai-chroma-data` | `/app/data/chroma` | ChromaDB 벡터 데이터 |

#### 운영 배포 환경 (Jenkinsfile)

Jenkins Pipeline으로 Docker 이미지 빌드 후 개별 `docker run` 실행합니다.

**배포 순서:**

```
1. BE Docker Build   → tax-backend 이미지 빌드
2. FE Docker Build   → tax-frontend 이미지 빌드
3. Prepare AI Model  → /opt/tax7i/models/tax_classifier → ai/models/ 복사
4. AI Docker Build   → tax-ai 이미지 빌드
5. Deploy            → 기존 컨테이너 정지/삭제 → 새 컨테이너 실행
```

**운영 포트 매핑:**

| 서비스 | 컨테이너 내부 포트 | 호스트 외부 포트 | 컨테이너명 |
|--------|-------------------|-----------------|-----------|
| Backend (Spring Boot) | 8080 | **18080** | `tax-backend` |
| Frontend (Nginx) | 80 | **3000** | `tax-frontend` |
| AI Service (Uvicorn) | 8000 | **19000** | `tax-ai` |

- Docker 네트워크: `ubuntu_default` (컨테이너 간 통신)
- 타임존: Backend `TZ=Asia/Seoul`
- 환경변수 파일: `/home/ubuntu/.env.backend`, `/home/ubuntu/.env.ai`

**운영 볼륨 마운트:**

| 컨테이너 | 호스트 경로 | 컨테이너 경로 | 용도 |
|----------|-----------|-------------|------|
| tax-backend | `/home/ubuntu/firebase-service-account.json` | 동일 경로 (read-only) | FCM 서비스 계정 |
| tax-ai | `chroma-data` (Docker Volume) | `/app/data/chroma` | ChromaDB 데이터 |

**AI 모델 파일:**
- 빌드 전 `/opt/tax7i/models/tax_classifier`에 모델 배치 필요
- Jenkins가 자동으로 `ai/models/tax_classifier/`로 복사
- 미배치 시 LLM 기반 분류만 사용 (분류기 없이 동작)

#### Nginx 리버스 프록시 (`FE/nginx.conf`)

```nginx
server {
    listen 80;
    server_name localhost;
    root /usr/share/nginx/html;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;   # SPA 라우팅
    }

    location /api/ {
        proxy_pass http://tax-backend:8080;  # 백엔드 프록시
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

## 3. DB 덤프 파일

### 초기화 SQL 파일 (5개)

| 순서 | 파일 | 설명 | 필수 여부 |
|------|------|------|----------|
| 1 | `db/init/01_schema.sql` | 22개 테이블 DDL | **필수** |
| 2 | `db/init/02_seed_data.sql` | 초기 시드 데이터 (가맹점 84개, 카드 상품, 테스트 계정) | **필수** |
| 3 | `db/init/03_sync_tax_seed_data.sql` | 2025년 세금 기준 데이터 동기화 (세율 구간 8개, 기한 6개, 파라미터) — 멱등성 보장 | **필수** |
| 4 | `db/init/04_test_book_entries.sql` | 테스트 결제내역 (1인 IT개발자 간편장부, 20개 세목 커버) | 선택 (시연용) |
| 5 | `db/init/05_fix_book_entry_amounts.sql` | 장부 금액 보정 (공급가액 → 원래 결제금액 복원) | **필수** |

> `04`는 시연 데모용 테스트 데이터입니다. 시연 없이 운영만 할 경우 생략 가능합니다.

- `docker-compose.yml` 사용 시 최초 기동 때 `db/init/` 디렉토리가 파일명 순서(01→05)로 자동 실행됨
- 운영 DB에서 `03~05`는 수동 실행 필요: `psql -U ssafy -d tax7i -f <파일>`
- JPA DDL 전략: `hibernate.ddl-auto: update` (앱 기동 시 스키마 자동 갱신)
- 운영 DB 덤프가 필요한 경우:

```bash
pg_dump -h <DB_HOST> -U ssafy -d tax7i --no-owner --no-privileges > exec/db_dump.sql
```
