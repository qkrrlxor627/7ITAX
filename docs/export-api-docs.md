# 7iTAX 내보내기 API 문서

## 내보내기 가능한 파일 목록

| # | 엔드포인트 | 형식 | 파일명 | 설명 |
|---|-----------|------|--------|------|
| 1 | `GET /api/export/book-entries` | CSV | `간편장부_{year}.csv` | 간편장부 전체 거래내역 |
| 2 | `GET /api/export/vat` | CSV | `부가세_{year}_{half}기.csv` | 부가가치세 신고 요약 |
| 3 | `GET /api/export/income-tax` | CSV | `종합소득세_{year}.csv` | 종합소득세 신고 요약 |
| 4 | `GET /api/export/local-tax` | CSV | `지방소득세_{year}.csv` | 지방소득세 신고 요약 |
| 5 | `GET /api/export/simple-ledger/pdf` | PDF | `간편장부_{year}.pdf` | 간편장부 (국세청 양식 A4 가로) |
| 6 | `GET /api/export/vat/excel` | XLSX | `부가세_{year}_{half}기.xlsx` | 부가세 신고서 (3시트) |
| 7 | `GET /api/export/income-tax/excel` | XLSX | `종합소득세_{year}.xlsx` | 종합소득세 신고서 (3시트) |
| 8 | `GET /api/tax/returns/{id}/pdf` | PDF | `tax-return-{id}.pdf` | 종합소득세 확정신고서 (3페이지) |
| 9 | `GET /api/tax/returns/{id}/receipt` | PDF | `tax-receipt-{id}.pdf` | 납부확인서 |

---

## 공통 사항

- **인증:** Bearer Token (Authorization 헤더)
- **CSV 인코딩:** UTF-8 + BOM (Excel 한글 호환)
- **Content-Disposition:** `filename=` + `filename*=UTF-8''` (RFC 6266)
- **데이터 필터:** 확정(confirmed=true) + 사업용(isBusinessExpense=true) 장부만 포함
- **페이지네이션:** 대용량 데이터는 500건 단위 페이징 처리

## 1. 간편장부 CSV

**`GET /api/export/book-entries?year={year}`**

| 파라미터 | 타입 | 필수 | 설명 |
|---------|------|------|------|
| `year` | Integer | X | 귀속연도 (기본: 올해) |
| `startDate` | Date | X | 시작일 (YYYY-MM-DD) |
| `endDate` | Date | X | 종료일 (YYYY-MM-DD) |

> `startDate`/`endDate` 둘 다 있으면 기간 조회, 없으면 `year` 기준 1.1~12.31

### 생성 파일 구조

```csv
일자,계정과목,거래내용,거래처,수입금액,수입부가세,비용금액,비용부가세,자산증감금액,자산부가세,사업용여부,비고
2025-03-15,지급수수료,카페 결제,스타벅스,0,0,15000,1500,0,0,사업용,
2025-03-16,매출,용역대금 입금,클라이언트A,5000000,500000,0,0,0,0,사업용,3월 계약분
```

**12개 컬럼:**

| 컬럼 | 내용 | INCOME일 때 | EXPENSE일 때 | ASSET일 때 |
|------|------|------------|-------------|-----------|
| 일자 | entryDate | O | O | O |
| 계정과목 | categoryName | O | O | O |
| 거래내용 | description | O | O | O |
| 거래처 | merchantName | O | O | O |
| 수입금액 | incomeAmount | **값** | 0 | 0 |
| 수입부가세 | vatAmount | **값** | 0 | 0 |
| 비용금액 | expenseAmount | 0 | **값** | 0 |
| 비용부가세 | vatAmount | 0 | **값** | 0 |
| 자산증감금액 | fixedAssetAmount | 0 | 0 | **값** |
| 자산부가세 | vatAmount | 0 | 0 | **값** |
| 사업용여부 | isBusinessExpense | "사업용"/"개인용" | | |
| 비고 | note | | | |

## 2. 부가가치세 CSV

**`GET /api/export/vat?year={year}&half={half}`**

| 파라미터 | 타입 | 필수 | 설명 |
|---------|------|------|------|
| `year` | Integer | X | 귀속연도 (기본: 올해) |
| `half` | Integer | X | 1=1기(1~6월), 2=2기(7~12월). 기본: 1 |

### 생성 파일 구조

```csv
부가가치세 신고 요약,2025년 1기

구분,공급가액,부가세액
매출,50000000,5000000
매입(공제),30000000,3000000

납부(환급) 예상세액,,2000000
```

**계산 로직:**
- 매출 = INCOME 엔트리의 supplyPrice/vatAmount 합계
- 매입 = EXPENSE 중 isVatDeductible=true인 엔트리의 supplyPrice/vatAmount 합계
- 납부세액 = 매출 부가세 - 매입 부가세

## 8. 종합소득세 확정신고서 PDF

**`GET /api/tax/returns/{id}/pdf`**

| 파라미터 | 타입 | 필수 | 설명 |
|---------|------|------|------|
| `id` | Long | O | 세금 신고 ID |

### 생성 파일 구조 (A4 세로, 3페이지)

**1페이지: 확정신고서**
- 납세자 정보 (성명, 주민번호, 귀속연도, 접수번호, 신고상태, 제출일)
- 소득 내역 (총수입금액, 필요경비, 소득금액)
- 소득공제 내역 (공제항목별 금액, 합계)
- 세액 계산 (과세표준, 세율, 산출세액, 결정세액, 기납부세액, 납부할 국세, 지방소득세, 총 납부세액)

**2페이지: 필요경비명세서**
- 번호 / 경비코드 / 경비항목 / 금액
- 필요경비 합계

**3페이지: 간편장부소득금액계산서**
- 1~12번 항목 (총수입 → 필요경비 → 소득금액 → 공제 → 과세표준 → 세율 → 산출세액 → 결정세액 → 기납부 → 국세 → 지방세 → 총 납부)
